# Setup

1. Install Homebrew: https://brew.sh
2. Clone and run the installer:
   ```sh
   git clone <your-repo-url> ~/zsh-setup
   ~/zsh-setup/install.sh
   exec zsh
   ```
3. macOS Terminal: Settings → Profiles → Keyboard → enable "Use Option as Meta key" (for Alt-C).

Edit files in `~/zsh-setup`, then commit and push.
